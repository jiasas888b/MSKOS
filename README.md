# MSKOS

![GitHub All Releases](https://img.shields.io/github/downloads/jiasas888/MSKOS/total)

此应用是一个在安卓端运行的应用式系统模拟框架以技术测试ui界面

此外也是马帅工作室的一个官方应用，内置计算器和日历应用以及可以快速打开马帅城市和马帅快快跑。系统将不断更新

### 支持
* MSKOS 1.2支持Android 7+
* MSKOS 1.1支持Android 6+
* MSKOS 1.0支持Android 5.1+

## 迭代
